## Всё для вашей коллекции

| Возможность | Что можно делать |
| :--- | :--- |
| **Коллекция** | Сохранять тайтлы, выставлять оценки, добавлять в избранное и отмечать статус просмотра. |
| **Продолжить просмотр** | Возвращаться к серии с сохранённой позиции и видеть историю просмотра. |

## Установка

1. Откройте [последний релиз](https://github.com/sdukaev58-tech/ANITEKA/releases/latest).
2. Скачайте файл **Aniteka_Setup_…exe** из раздела **Assets**.
3. Запустите установщик и следуйте его шагам.
4. Откройте Aniteka через меню «Пуск» или ярлык на рабочем столе.

**Требования:** Windows 10 или 11, 64-разрядная система. Для интерфейса нужен Microsoft Edge WebView2 Runtime; установщик предложит установить его, если он отсутствует. Для загрузки каталога и просмотра необходим интернет.

### Обновление и перенос

Новую версию можно установить поверх предыдущей. Коллекция и настройки установленного приложения хранятся отдельно от программы.

Перенос из старой портативной Aniteka **необязателен**: отметьте соответствующий пункт в установщике только если хотите перенести прежнюю коллекцию.
